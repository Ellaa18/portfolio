# Components

This project has no separate reusable component directory. The UI is currently composed inline in `script.jsx`.

## Inline UI patterns
- Navigation: `.site-header` in `script.jsx`
- Project cards: `.project-card` map in `script.jsx`
- Contact dialog: `.chat-panel` conditional render in `script.jsx`
- Buttons and form controls: inline JSX with shared CSS classes in `style.css`

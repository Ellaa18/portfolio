# Theme

## Token summary
- Framework: React + Vite
- CSS: vanilla stylesheet in `style.css`
- Current palette: navy `#171e19`, white `#ffffff`, sage `#b7c6c2`, cyan `#d5f4f9`, soft blue `#bbe2f5`, taupe/muted `#77716f`
- Fonts: Anton display, Plus Jakarta Sans body, DM Mono metadata
- Layout: max-width 1180px, responsive breakpoint 760px
- Motion: IntersectionObserver reveals, ambient float, orbit, silhouette drift, hover transforms

## Source
- `style.css` contains all design tokens, responsive layout, component styles, modal styles, and keyframes.
- `index.html` loads Google Fonts and mounts `#root`.
